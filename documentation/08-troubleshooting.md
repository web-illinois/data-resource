# Troubleshooting and FAQ

**I'm told to choose a source.**
Select one on the home page. The tool needs an active source before editing.

**I can't see an item type (for example, Events).**
It is not enabled for your source. Ask a source administrator.

**I see "limited access."**
Your permissions on this source are restricted. Contact the source owner.

**My changes disappeared.**
Each page has its own **Save** button. Save before navigating away.

**The URL fragment is rejected.**
Use only lower-case letters, numbers, dashes, and `/`, and make it unique. Otherwise, leave it blank.

**An image doesn't show.**
Confirm it uploaded and that the item was saved. Add alternate text.

**I want to try things without risk.**
Use **Access Test Source** on the home page.

**Who do I contact for more help?**
Use the **Contact Us** page in the tool.
