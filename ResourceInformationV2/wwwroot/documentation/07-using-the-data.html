Using the Data

Source code

Each source has a code displayed on the home page under Active Source. Provide this code to the API to retrieve that source's items.

Search

The API supports searching by text and by category (filters). Tag items carefully so they appear in expected results.

Importing and exporting

Use the Transfer Items pages to export data as a tab-delimited text file or JSON, or to import it. See Importing and Exporting Data.

Deleting a source's data

Source configuration includes a deletion page. This is permanent. Download your data first.
