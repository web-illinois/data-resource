# Adding and Editing Items

## Item types
| Type | Use it for |
|------|-----------|
| Resource | A generic item such as a lesson plan or education resource |
| Publication | A resource with extra fields such as book title and author |
| Event | A resource with dates, times, locations, and speakers |
| Person | Names, departments, and job titles (not linked to Banner, Illinois Experts, or EDW) |
| FAQ | A question with a rich-text answer |
| Note | A resource with a rich-text description |

## Add an item
1. From the home page, select **Add New** on the item type's card, or use **Add Items** and choose a type.
2. Complete the **General Information** page and select **Save**.
3. Use the sidebar to continue to other pages, such as **Image and Video** and **Filters**. Each page has its own **Save** button.

## General Information fields (Resources)
- **Title**: The name of the item.
- **Link** and **Link Text**: The destination URL and the text displayed for it.
- **Description**: A summary of the item.
- **URL Fragment** (when enabled): A unique value used to make the item easier to find and to meet SEO standards. Use only lower-case letters, numbers, dashes, and `/`. If you cannot meet these rules, leave it blank and rely on the item ID.

Other item types have similar pages with type-specific fields.

## Edit an item
1. On the home page, select **Edit** for the item type (for example, **Edit Resources**).
2. Select the item from the list.
3. Change the fields and select **Save** on each page you modify.

## Unsaved changes
The tool tracks changes you have not saved. Select **Save** before leaving a page.

## Delete an item
Use the delete option on the item's edit page. Deleted items cannot be recovered from the tool, so confirm before deleting.
