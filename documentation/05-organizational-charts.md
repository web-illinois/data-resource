# Organizational Charts

An organizational chart is a standalone hierarchy showing relationships between entities. **Each source can have only one chart.**

## Edit the chart
1. On the home page, select **Edit Org Chart** (or choose **Organization Chart** under **Add Items**).
2. Add or change entries, arranging them to reflect the hierarchy.
3. Select **Save**.

The Org Chart card appears only if it is enabled for your source.
