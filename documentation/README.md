### Who supports this application?

The application is maintained by WIGG and the University Website Management Center of Expertise group. This application is meant for campus, so we cannot customize it for a specific unit unless others will benefit from the change.

### Can I get information from the repository?

Yes. The Resource API pulls items into your web page. The application is meant to be used with the Illinois Toolkit, although it can be used alone. The [Toolkit Builder](https://builder3.toolkit.illinois.edu) has examples of how to integrate it.

### History

In 2020, Nancy Latham, the Executive Director of the Council on Teacher Education (CoTE), needed a way to list resources for K-12 teachers teaching remotely. The list needed to be searchable, filterable, and easy to manage. IT Partners at Education (Bryan Jonker, Elaine Robbins, and Tovah Irwin) built a tool that let people upload Excel worksheets and display them as individual items on a page. Amanda Heinsman became the curator of the list, and the tool was improved to allow changes without the Excel format.

IT Partners realized the tool could be used for other purposes. The Office of Community College Research and Leadership (OCCRL) became the second user in 2021 and needed publication information with specialized fields, so those fields were added to the publication option.

Other areas have used the tool as well, and improvements have followed their feedback. In 2025 the tool was rewritten in a new framework with more publishing options such as People, FAQs, and Events. In 2026 the tool was transferred to WIGG and the University Website Management Center of Expertise group.
