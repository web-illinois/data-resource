Link Checks

A link check confirms that the links on your resources resolve to a working website. Open Review > Validate Links to use it.

The check only tests whether a link resolves to a website. It does not detect whether the page has moved or been repurposed.

Schedule a link check

  1. Open Review > Validate Links.
  2. Select Schedule Link Check.
  3. Return to the page later to see progress.

You cannot schedule a second check while one is in progress. In that case, the button is replaced with the status only.

How long it takes

The process checks about 60 links an hour, so a large source can take several days. Check back on the page for:

  • Last Link Check: the date of the most recent check.
  • Number of Links Left to Check: how many links remain.

What happens to bad links

  • A link that does not resolve is converted to Draft mode and no longer appears in searches.
  • Under List of Bad Links, each entry shows the title (linked to the URL), the response message, and an Edit Resource link. The list stays until you run another link check.
  • For a live list of everything currently in draft, use the View Drafts page (/review/viewdrafts).

Fixing a bad link

  1. Select Edit Resource beside the link.
  2. Correct the URL and save.
  3. Move the item out of draft, following your normal review process.

Links that are wrongly flagged

Some websites block automated checks, so a good link may be reported as not resolved. For that resource, open the technical area of the item and select Use Manual Check. The link will no longer be sent to draft when it does not resolve. You are then responsible for checking it yourself.

Tips

  • Schedule a link check regularly, for example each term.
  • Use it together with the review process.
  • If many links fail at once, confirm the websites are not simply down before editing items.
