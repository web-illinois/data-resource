Getting Started

What is the WIGG Resource Application?

The WIGG Resource Application is a web tool for editing resources, publications, events, people, FAQs, notes, and organizational charts. The information is available through an API, where it can be searched by text and category.

Key terms

  • Source: A collection of items shown on a web page, usually driven by a project. A project can have more than one source, and a source can hold multiple item types (for example, resources and publications).
  • Item types: Resources, Publications, Events, People, FAQs, Notes, and Organizational Chart. Only the types enabled for your source appear.
  • Source code: The identifier you give to the API to retrieve a source's data. It is shown on the home page under Active Source.

Choosing a source

  1. Sign in and open the home page.
  2. If you have access to more than one source, select one under Choose a Source. You must do this before editing.
  3. The home page then shows the Active Source and a card for each enabled item type.

If you see "You must choose a source before continuing," return to the home page and select one.

If you see "You have limited access to this source," you can view the source but some actions may be unavailable. Contact the source owner for more access.

Creating a source

On the home page, select Create a New Source under Create a Source and follow the prompts.

Practicing safely

Select Access Test Source to add yourself to a test source. You can add, change, and delete items there without affecting real data.
